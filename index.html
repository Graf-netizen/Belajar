Prompt AI

Salin prompt ini ke ChatGPT, Claude, atau Gemini agar soal dibuat sesuai format aplikasi. Hasilnya terdiri dari dua bagian: stimulus (File 1) dan soal (File 2). Pilih mode stimulus yang sama dengan pilihan di Kelola Soal.

Folder Baru

Tambah Materi

PDF, TXT, dan gambar. Bisa lebih dari satu file (maks. 20 MB per file).

Awali baris dengan # untuk judul bagian dan - untuk poin. Rumus ditulis di antara tanda $, misalnya $x^2+1$. Gambar hanya bisa disimpan di mode File.

Pengaturan Materi

Dua cara menyimpan

  • File: PDF, TXT, atau gambar disimpan utuh seperti aslinya. Satu materi bisa berisi banyak file.
  • Teks: isi diketik atau diimpor dari PDF/TXT, lalu bisa diedit. Awali baris dengan # untuk judul dan - untuk poin. Tombol Sambung baris terpotong merapikan teks hasil PDF.

Gambar

Gambar hanya bisa disimpan lewat mode File, bersama file lain atau sendirian. Mode Teks tidak menyimpan gambar.

Mengubah bentuk kapan saja

  • File → Teks: PDF dan TXT diubah 1:1 menjadi teks. PDF hasil scan tidak bisa dibaca. Gambar tidak ikut diubah dan akan dihapus.
  • Teks → File: teks disimpan menjadi satu file .txt, lalu kamu bisa menambah file dan gambar lain.
  • Perubahan baru berlaku setelah menekan Simpan Materi.

Rumus

Pada materi teks, tulis rumus dengan LaTeX di antara tanda dolar, misalnya $\frac{a}{b}$.

Penyimpanan

Semua materi dan file tersimpan di browser perangkat ini (maks. 20 MB per file). Menghapus data browser akan menghapus materi.

Cadangan Data

Semua paket soal, materi (termasuk file dan gambar), dan riwayat tersimpan di perangkat ini. Simpan cadangan sebelum ganti HP, ganti browser, atau menghapus data situs.

Simpan cadangan

Menghasilkan satu file .json berisi semua data.

Pulihkan cadangan

Data di perangkat ini akan diganti dengan isi file cadangan.

Cara Mengisi Paket Soal

Langkah singkat

  1. Pilih folder tujuan. Nama paket boleh dikosongkan.
  2. Pilih cara menampilkan stimulus: Teks atau File.
  3. Pilih File 1 (stimulus): PDF/TXT untuk mode Teks, PDF atau gambar untuk mode File.
  4. Pilih File 2 (soal) berformat PDF/TXT.
  5. Bila perlu, tekan Ubah Soal untuk memperbaiki teks hasil baca file sebelum diproses.
  6. Tekan Proses Soal. Paket muncul di Paket Tersimpan.
  7. Ketuk paket di Paket Tersimpan untuk mengedit per soal.

PDF dibaca sebagai teks. PDF hasil scan atau foto tidak bisa dibaca. Untuk membuat soal dengan AI, pakai Pengaturan › Buat Prompt AI.

Dua cara menampilkan stimulus

Teks: File stimulus diubah menjadi teks, jadi stimulus dan soal tampil sebagai teks. Tiap stimulus diawali ###. PDF scan/foto tidak bisa dibaca.

File: File (PDF atau gambar) disimpan apa adanya dan terbuka otomatis saat ujian. 1 stimulus = 1 halaman PDF (atau 1 gambar), tidak perlu ###. Saat ujian stimulus bisa diperbesar/diperkecil (tombol +/−, Ctrl + roda mouse, atau cubit dua jari) dan dibuka layar penuh. PDF scan pun bisa dipakai. Jumlah halaman harus sama dengan jumlah stimulus.

Matematika: pilih mode File bila stimulus memuat grafik, tabel, bangun datar, atau rumus bersusun yang rusak saat diubah menjadi teks. Pilih mode Teks bila stimulus hanya cerita pendek dengan rumus sederhana. Di kedua mode, soal (File 2) tetap berupa teks dengan rumus LaTeX di antara tanda dolar. Pada mode File, beri label seperti “Gambar 1” atau “Tabel 1” di halaman stimulus agar soal bisa merujuknya.

Aturan Matematika

Tiap 3 soal memakai 1 stimulus: 1 Pilihan Ganda, 1 PG Kompleks, dan 1 PG Kategori (Benar/Salah, Setuju/Tidak Setuju, dll). Urutan ketiganya bebas. Jenis dikenali otomatis: ada baris Kategori: → PG Kategori, kunci berisi lebih dari satu huruf → PG Kompleks, selain itu → Pilihan Ganda. Jika File 1 tidak memakai ###, teksnya dipakai untuk semua soal.

Kunci: Benar, Salah, Benar
Pembahasan: penjelasan singkat

Urutan kunci sama dengan urutan pernyataan.

Format stimulus (File 1, mode Teks)

Awali tiap stimulus dengan ###. Baris yang terpotong di PDF otomatis disambung, dan jarak antarparagraf tetap terbaca.

### Stimulus 1
Teks wacana pertama...

### Stimulus 2
Teks wacana kedua...

Rumus matematika

Stimulus, pertanyaan, opsi, dan pembahasan mendukung LaTeX. Tulis rumus di antara tanda dolar: $x^2+3x$, $\frac{a}{b}$, $\sqrt{16}$. Untuk tanda dolar biasa, tulis \$.

Gambar stimulus (opsional)

Gambar selalu tampil di atas teks stimulus. Tulis [gambar 1] di stimulus yang memakainya, misalnya ### Stimulus 1 [gambar 1]. Tanpa penanda, gambar #1 dipasang di Stimulus 1, #2 di Stimulus 2, dst.
